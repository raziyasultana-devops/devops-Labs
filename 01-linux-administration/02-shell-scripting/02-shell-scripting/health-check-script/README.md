
# Linux System Health Check Script

## Overview
A Bash scripting project to check important
Linux system health metrics.

## Objectives
- Monitor CPU utilization.
- Check memory usage.
- Check disk utilization.
- Monitor system uptime.
- Generate a health report.

## Commands Used
- uptime
- free -h
- df -h
- top
- hostname
- date

## Implementation
1. Collect system information.
2. Check memory utilization.
3. Check filesystem usage.
4. Capture system uptime.
5. Display or save a health report.

## Learning Outcome
Understand basic Linux monitoring
and automate system health reporting.
