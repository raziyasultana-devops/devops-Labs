
# Linux Automated Backup Script

## Overview
A Bash scripting project for automating
file and directory backups.

## Problem Statement
Regular backups help protect important
data against accidental loss.

## Tools Used
- Bash
- tar
- date
- mkdir
- cp
- chmod

## Implementation
1. Define source and backup directories.
2. Create a timestamp for each backup.
3. Archive the selected files.
4. Store the backup in the destination.
5. Verify that the backup was created.

## Key Concepts
- Backup automation
- File archiving
- Timestamp management
- Shell scripting

## Learning Outcome
Understand how to automate Linux backups
using Bash scripting.
