
# Linux Cron Heartbeat Automation

## Overview
A Linux automation exercise that uses cron
to execute a scheduled heartbeat script.

## Problem Statement
Scheduled commands can run silently unless
their output is redirected to a log file.

## Tools Used
- Bash
- Cron
- crontab
- date
- chmod
- Linux logging

## Implementation
1. Create a heartbeat shell script.
2. Make the script executable.
3. Configure a cron schedule.
4. Redirect output to a log file.
5. Verify scheduled execution.

## Key Concepts
- Job scheduling
- Cron configuration
- Shell automation
- Logging and auditing
- Script execution permissions

## Learning Outcome
Understand how to schedule recurring Linux
tasks and maintain an execution audit trail.
