
# Automated Cleanup Script

## Overview
A Bash scripting project for automating
the cleanup of unnecessary files.

## Problem Statement
Old temporary files can consume disk space
and make system maintenance difficult.

## Tools Used
- Bash
- Linux
- find
- rm
- date
- chmod

## Implementation
1. Define the target directory.
2. Identify files matching cleanup criteria.
3. Remove eligible files.
4. Record execution details in a log.
5. Verify cleanup results.

## Key Concepts
- Shell scripting
- File management
- Automation
- Logging
- Script permissions

## Learning Outcome
Understand how Bash scripts can automate
routine Linux maintenance tasks.

## Safety
Test cleanup scripts on a dedicated test
directory before deleting any files.
