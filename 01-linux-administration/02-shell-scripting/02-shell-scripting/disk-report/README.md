
# Linux Disk Report

## Overview
A hands-on Linux storage reporting exercise
to generate a consolidated disk usage report.

## Problem Statement
System administrators need a quick overview
of available storage, filesystem utilization,
and large directories.

## Commands Used
- lsblk
- df -h
- du
- sort

## Implementation
1. List block devices.
2. Check filesystem utilization.
3. Analyze /var directory sizes.
4. Sort directory sizes.
5. Generate a consolidated report.

## Expected Output
A report containing:
- Block device information
- Filesystem usage
- Directory size breakdown

## Learning Outcome
Understand Linux storage reporting and
command-line administration.
