
# Linux Environment Variables and PATH

## Overview
Practical exercises on Linux environment
variables and shell configuration.

## Topics
- Environment variables
- Local and global variables
- Export command
- PATH configuration
- .bashrc configuration
- Persistent environment settings
- Executable scripts

## Commands Used
- printenv
- env
- export
- echo
- source
- which
- chmod

## Practical Exercises
- Configure EDITOR variable.
- Configure LANG variable.
- Update PATH.
- Make custom scripts executable.
- Persist environment variables in .bashrc.

## Learning Outcome
Understand shell environment configuration
and executable command management in Linux.
