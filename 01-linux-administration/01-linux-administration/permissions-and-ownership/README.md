
# Linux Permissions and Ownership

## Overview
Practical exercises on Linux file permissions,
ownership, and security management.

## Topics
- File permissions
- chmod
- chown
- chgrp
- Numeric permissions
- Symbolic permissions
- User and group ownership
- SSH directory permissions
- Secrets file protection

## Commands Used
- ls -l
- chmod
- chown
- chgrp
- stat

## Learning Outcome
Understand Linux access control and
secure files using appropriate permissions.
