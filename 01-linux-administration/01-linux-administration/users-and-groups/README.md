
# Linux Users and Groups Management

## Overview
Practical exercises on Linux user and group administration.

## Topics
- Creating Linux users
- Modifying user accounts
- Deleting users
- Creating groups
- Adding users to groups
- Managing user permissions
- Understanding /etc/passwd
- Understanding /etc/group

## Commands Used
- useradd
- usermod
- userdel
- groupadd
- groupdel
- passwd
- id
- groups
- whoami

## Learning Outcome
Understand Linux user administration,
group management, and access control.
