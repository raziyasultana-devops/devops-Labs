
# Linux Process Management

## Overview
Hands-on Linux process management and
troubleshooting exercises.

## Topics
- Understanding Linux processes
- Process IDs (PID)
- Parent and child processes
- Foreground and background processes
- Process monitoring
- Process termination
- Process signals
- Process lifecycle

## Commands Used
- ps
- top
- htop
- pgrep
- kill
- jobs
- bg
- fg
- sleep

## Learning Outcome
Understand process lifecycle, monitor running
processes, and troubleshoot process-related issues.
